# Security Policy

## Reportar un bug de seguridad

1. Abre un issue con label `security`
2. Describe el vulnerabilidad sin exponerla públicamente
3. Incluye pasos para reproducir

## Requisitos

- No incluir credenciales en el repo
- No exponer bases de datos en logs
- Tokens de API rotados periódicamente

## Versiones soportadas

| Versión | Soportada |
|---|---|
| Master (último commit) | Sí |
| Tags de release | Sí |
